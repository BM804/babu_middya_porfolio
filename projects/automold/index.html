AUTOMOLD

Turn an STL model into a reviewable two-part mold concept—with one Python command.

Why I built it

Preparing a first-pass mold from a 3D mesh involves repetitive geometry work: splitting the part, cutting cavities, sizing plates, and adding alignment features.

What it does

AUTOMOLD reads an STL, repairs and validates the mesh where possible, selects a parting plane, creates top and bottom mold halves with cavities and alignment features, then exports a preview assembly and a dimensioned drawing.

How it works

  1. Load and inspect an STL mesh.
  2. Choose a mid-height or user-specified parting plane.
  3. Create mold plates and subtract the part geometry to form cavities.
  4. Add alignment pins and matching clearance holes.
  5. Export both mold halves, an exploded STL preview, and a 2D drawing.

Outcome

A command-line prototype that automates repetitive first-pass geometry creation for simple two-part molds. Output is intended for review and prototyping; an engineer still needs to assess draft, undercuts, material shrinkage, and production tolerances.

Tools and technologies

Python trimesh Manifold3D NumPy Matplotlib argparse

Scope and limitations

The parting plane is a geometric choice; the tool does not perform full manufacturability analysis or produce certified production drawings.
