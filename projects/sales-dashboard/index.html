Sales Performance Dashboard

A reproducible analytics workflow that takes raw order data through cleaning and SQL analysis to a Power BI dashboard.

View GitHub repository ↗ Portfolio projects
Python data cleaning 14 SQL analysis queries SQLite database Power BI build guide

Why I built it

Sales exports can contain missing values, duplicates, inconsistent text, and dates that are difficult to analyze consistently.

What it does

This project demonstrates an end-to-end workflow: generate or load sample order data, clean and prepare it with Python, store it in SQLite, answer business questions with SQL, and build a Power BI dashboard from the prepared dataset.

How it works

  1. Generate a reproducible synthetic Superstore-style dataset or supply a compatible source file.
  2. Clean missing, duplicate, inconsistent, and invalid values with Python.
  3. Load the cleaned data into SQLite.
  4. Run SQL queries for sales, profit, product, customer, region, and discount analysis.
  5. Use the included Power BI guide and preview charts to assemble the dashboard.

Outcome

The repository includes runnable data-preparation scripts, a SQLite workflow, 14 analysis queries, dashboard preview images, and a Power BI build guide. The example figures come from synthetic data and are for demonstration.

Tools and technologies

Python Pandas NumPy SQL SQLite Excel Power BI Matplotlib

Scope and limitations

The sample figures are generated from synthetic demonstration data. They should not be presented as real customer or business results.
