Why I built it

Industrial sales discussions involve coordinating customer requirements, delivery resources, costs, and negotiation scenarios in one place.

What it does

Forge Sales Desk is a web workspace prototype for organizing industrial sales planning and resource-costing scenarios. It can run as an illustrative frontend without environment setup; an optional API and PostgreSQL configuration is documented separately.

How it works

  1. Open the deployed workspace or run the project from its repository instructions.
  2. Explore the illustrative sales planning and costing workflow.
  3. Use the browser-local mode to try edits without configuring a backend.
  4. Configure the optional API and PostgreSQL service by following the repository handover guide.

Outcome

A prototype that demonstrates the planned interface and workflow. The repository explicitly marks its records as illustrative; use verified customer outcomes before presenting business impact.

Tools and technologies

Web application JavaScript Vercel Optional API PostgreSQL

Scope and limitations

Workspace records are illustrative, and browser-only changes are stored locally. The optional server-backed mode requires separate API and database setup.
